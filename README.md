# RoboLens Booth

Orangewood's Robotic Arm Photobooth Software

![screenshot](./images/screenshot.png)

## Functionalities

- Robot move selector.
- Automatic photo and video capturing.

## Installation

- Install [Node.js](https://nodejs.org/en/) (version 12.18.3 or higher).
- Clone this repository.
- Run `npm install` in the root directory of this repository.
- Run `npm run dev` to start the application. This will start the frontend servers. Now you need to start the backend server.
- To view the application, open a browser and go to `localhost:3000`.
